# Product Guidelines - USB Over Network (USB-Share)

## 1. Design Principles (UX/UI)
- **极简实用主义 (Minimalist)**
    - 界面应极其简洁，去除所有非必要装饰。
    - 采用原生 Windows 控件风格，确保轻量化和响应速度。
    - 操作路径应最短化（例如：列表选择 -> 分享/连接）。
    - 避免复杂的多层级菜单，核心功能一目了然。

## 2. Engineering Standards (Performance & Stability)
- **极致稳定性优先 (Rock-Solid)**
    - 设计目标是“连接一次，稳定运行”。
    - 引入健壮的缓冲机制和校验算法，确保数据包在 TCP 传输中的完整性。
    - 容忍一定的网络延迟以换取数据流的绝对连续，防止因丢包导致的 USB 设备复位或断开。
    - 驱动层应具备异常恢复能力，即使上层应用崩溃，也不应导致系统蓝屏或死锁。

## 3. Distribution & Deployment
- **绿色免安装 (Portable)**
    - 以单文件（或便携文件夹）形式发布，解压即运行。
    - 不依赖庞大的运行时环境（如重型 .NET 框架或 Java VM，除非系统自带）。
    - 驱动程序的安装应集成在主程序中，按需触发，并提供清晰的卸载清理选项。
    - 不随意写入系统注册表或非必要的系统目录。

## 4. Logging & Diagnostics
- **详尽追踪 (Verbose/Trace)**
    - 默认启用或提供简单的切换开关来开启详细的调试日志。
    - 记录完整的 USB 请求块 (URB) 交互流程和 TCP/IP 数据包状态。
    - 日志应包含时间戳、线程 ID 和详细的错误代码，以便于开发者分析兼容性问题。
    - 即使在发布版本中，也应保留核心的诊断能力。
