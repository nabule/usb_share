# Initial Concept
我要开发一个usb 共享程序，A和B电脑可以通过TCPIP共享自己本地插入的USB设备给对方。是最底层原生的共享模式，就相当于直接插入对方电脑，对方电脑需要具备相应的原始驱动才能使用。

# Product Definition - USB Over Network (USB-Share)

## 1. Vision & Goals
打造一个极简且高性能的底层原生 USB 设备共享工具。允许两台 Windows 电脑通过 TCP/IP 网络，将本地插入的 USB 设备（如加密狗、扫描仪等）以“原生插拔”的方式共享给远程电脑。远程电脑识别到的设备如同直接插入物理接口，确保所有原始驱动和功能完整可用。

## 2. Target Users
- **专业/极客用户**：需要在多台 Windows 设备间灵活共享加密狗 (Dongle) 或特定 USB 工具的用户。
- **远程办公/开发者**：需要远程访问物理 USB 设备进行调试或使用的场景。

## 3. Core Features (Phase 1)
- **底层原生共享**：在 USB 协议层进行拦截与转发，确保设备在远程电脑上呈现为原生状态。
- **TCP/IP 手动连接**：一期实现通过输入对方 IP 地址进行手动连接，适应各种网络拓扑。
- **局域网自动发现**：支持通过 UDP 广播自动搜索局域网内的可用共享端，简化连接流程。
- **设备管理与监控**：
    - **手动选择**：用户可从本地 USB 列表中手动指定要分享的设备。
    - **状态显示**：实时展示设备状态（本地、分享中、远程连接中）。
    - **自动重连**：网络波动导致断开后，程序自动尝试恢复之前的共享连接。
- **环境限制**：首期仅支持双端均为 Windows 系统的环境。

## 4. Future Roadmap (To be implemented)
- **发现机制**：支持局域网内的设备自动搜索。
- **交互优化**：提供系统托盘常驻程序。
- **安全加固**：
    - 访问密码保护。
    - IP 访问白名单限制。
    - 传输层原始数据加密。
